# Kiến trúc Hệ thống Truy xuất Nguồn gốc Hàng hóa – Bộ Công Thương

## I. KIẾN TRÚC TỔNG QUÁT

### 1. Đối tượng sử dụng

- Doanh nghiệp / Nhà sản xuất
- Cơ quan quản lý (Bộ Công Thương)
- Cơ quan quản lý khác (Bộ/Ngành)
- Người tiêu dùng
- Đối tác quốc tế

### 2. Ứng dụng nghiệp vụ

- Quản lý DN & người dùng
- Đăng ký sản phẩm / mặt hàng (16 nhóm)
- Quản lý chuỗi cung ứng (sản xuất, đóng gói, vận chuyển,...)
- Quản lý chứng từ & hồ sơ
- Quản lý rủi ro (cao/thấp)
- Cảnh báo & xử lý vi phạm
- Thu hồi sản phẩm (Recall)
- Báo cáo – Thống kê
- Quản trị hệ thống
- API Quản trị tích hợp
- Cổng thông tin (Portal)

### 3. AI & Phân tích

- Ghi nhận sự kiện (đánh giá rủi ro)
- Risk Scoring
- Phát hiện bất thường & gian lận
- Phân tích chuỗi cung ứng
- AI OCR & xử lý chứng từ
- Dự báo & cảnh báo

### 4. Kênh truy xuất

- Web Portal
- Mobile App
- QR Code
- API cho đối tác
- Chatbot

### 5. Nền tảng Quốc gia do Bộ Công An xây dựng

- **Blockchain nền tảng**: Ghi nhận bằng chứng, bảo đảm tính toàn vẹn dữ liệu
- **Master Data & Định danh hàng hóa**: Định danh mặt hàng, doanh nghiệp, địa điểm, đơn vị,...
- **Cơ sở dữ liệu Hàng hóa Quốc gia**: CSDL dùng chung giữa các Bộ/Ngành

> Kết nối, đồng bộ theo chuẩn API & định danh

### 6. Tích hợp liên Bộ/Ngành

- Bộ Nông nghiệp & PTNT
- Bộ Y tế
- Tổng cục Hải quan
- Bộ Khoa học & Công nghệ
- Tổng cục Thuế
- Bộ Tài chính
- Các hệ thống khác

## II. KIẾN TRÚC LOGIC

### 1. Kênh truy cập

- Web Portal
- Mobile App
- API / Webhook
- QR Code
- Chatbot

### 2. Tầng Trình diễn (Presentation Layer)

- Dashboard
- Quản lý nghiệp vụ
- Báo cáo – Thống kê
- Tìm kiếm – Truy xuất
- Cấu hình hệ thống

### 3. Tầng Nghiệp vụ (Business Layer)

- Quản lý tổ chức & người dùng
- Quản lý sản phẩm / mặt hàng (16 nhóm)
- Quản lý định danh (sản phẩm, lô, đơn vị)
- Quản lý chuỗi cung ứng
- Quản lý sự kiện (Event Management)
- Quản lý chứng từ
- Quản lý rủi ro
- Giám sát & cảnh báo (Risk Monitor)
- Xử lý vi phạm
- Thu hồi sản phẩm
- Báo cáo – Thống kê
- Quản trị hệ thống
- Cấu hình quy tắc
- Tích hợp API

### 4. Tầng Truy cập Dữ liệu (Data Access Layer)

- Repository
- Data Adapter
- Cache
- Search Engine
- API Client (Outbound)
- Message Queue

### 5. Tầng Dữ liệu (Data Layer)

- Cơ sở dữ liệu nghiệp vụ (RDBMS)
- Cơ sở dữ liệu chứng từ (Document DB)
- Kho lưu trữ tệp (Object Storage)
- Cache (Redis)
- Search Index (Elasticsearch)
- Data Warehouse (Phân tích, BI)

### 6. Tầng Dịch vụ Tiện ích

- AI & Machine Learning
- OCR & Xử lý chứng từ
- Thông báo (Email/SMS/Zalo)
- Workflow / Quy trình
- Log & Audit
- File/Document Service
- Task Scheduler

### 7. Tích hợp & Liên thông

- Nền tảng Blockchain – Bộ Công An (API đồng bộ sự kiện, chứng thực dữ liệu)
- Master Data & Định danh hàng hóa (API tra cứu, đồng bộ)
- CSDL Hàng hóa quốc gia
- Hệ thống của các Bộ/Ngành khác
